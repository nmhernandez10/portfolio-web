One-line: small mono pill for stack items, roles and status; the workhorse of the skills and work sections.

```jsx
<Tag>PostgreSQL</Tag>
<Tag tone="success" dot>Open to work</Tag>
<Tag tone="accent" size="sm">Feature Architect</Tag>
```

- Default tone is neutral; keep accent for one or two per group so gold stays meaningful.
- Status tones (success / info / danger) are the only place non-gold color appears.
