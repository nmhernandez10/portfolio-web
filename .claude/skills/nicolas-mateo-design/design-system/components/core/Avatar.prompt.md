One-line: portrait holder that degrades to mono initials when no photograph is available.

```jsx
<Avatar size="sm" initials="NH" />
<Avatar src="/assets/portrait.jpg" alt="Nicolás Mateo" size="xl" ring />
```

- No portrait shipped with this system yet, so every example uses the initials state.
- `shape="rounded"` matches --radius-media and is preferred for large editorial crops; circles stay small.
