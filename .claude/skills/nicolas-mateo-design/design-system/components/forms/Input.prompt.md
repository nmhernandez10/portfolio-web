One-line: single-line field with a mono uppercase label and a gold focus ring — used in the contact form.

```jsx
<Input label="Email" name="email" placeholder="you@company.com" />
<Input label="Email" error="That address looks incomplete." />
```

- 8px radius (--radius-input) — the only place in the system that is not a pill or a 14px card.
- Focus = gold border + 3px --gold-200 halo. Never a blue browser ring.
