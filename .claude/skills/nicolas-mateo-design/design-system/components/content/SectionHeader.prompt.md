One-line: every page section starts with this — hairline, numbered mono eyebrow, display heading, optional lede.

```jsx
<SectionHeader eyebrow="02 / Selected work" title="Systems I own end to end" lede="Four projects, each with the part I was responsible for." />
```

- Eyebrows are numbered in sequence across a page. It is the system's main wayfinding device.
- Headings stay under ~22ch so they break where intended.
